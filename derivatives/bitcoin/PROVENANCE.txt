READ THIS FIRST -- WHAT YOU ARE HOLDING, AND WHAT YOU ARE NOT
=============================================================

This package was assembled in 2026. It is NOT Satoshi Nakamoto's 2009 release, and it is not money.

It exists because the earliest Bitcoin client is usually discussed and rarely executed. To execute it
honestly you must run the real code -- so this package ships Satoshi's 2009 source almost entirely
unchanged, and starts a SEPARATE chain rather than touching the one he started.

The file `readme.txt` in this package reads:

    BitCoin v0.01 ALPHA
    Copyright (c) 2009 Satoshi Nakamoto

That is HIS file, preserved byte-for-byte. It is not a claim by us. The MIT licence he released the
code under requires that his notice travel with the code, and preserving it exactly is both the legal
obligation and the entire point of a reconstruction: bytes that have been "tidied up" prove nothing.

**So: every unqualified 2009 attribution you find inside this package is Satoshi's own text, kept
intact. Everything written by this project is dated 2026 and says so.**

WHY THOSE NINE AND NO OTHERS
----------------------------

Every one is CHAIN SEPARATION. Not one changes a consensus rule.

The network magic and port make this protocol-level incompatible with Bitcoin mainnet: a node built
here cannot connect to a mainnet node, and cannot relay a block or a transaction to one, even by
accident. The IRC channel keeps peer discovery separate. The genesis constants start a different
chain from block 0.

Subsidy, halving interval, difficulty retarget, script, serialization, the wire format and the wallet
are UNTOUCHED and byte-identical to 2009. That is deliberate: the value of running this client comes
entirely from it being the same program.

NOT MONEY
---------

This is a commitment about what THIS PROJECT does, and it is written that way on purpose:

  no premine of value        no token          no sale by us
  no offer by us             no price set      no value assigned in the coinbase

The coins are research artifacts and evidence of authorship. Nothing is owed to anyone who mines,
and nothing here is for sale.

WHAT WE CANNOT PROMISE, STATED PLAINLY
Anyone may find this software, run it, and mine. Whether a third party then values or trades those
units is outside any software's control, and outside ours. We do not solicit it, we do not
facilitate it, and nothing here invites it -- but we will not pretend to a guarantee we cannot give.

That distinction is deliberate. "We assign no value and make no sale" stays true whatever a stranger
does. "There is no market" would be a claim about the world, and the world is not ours to bind.

This is why a live node with a plaintext wallet and no script limits is safe to run at all: not
because no one could ever value these units, but because nothing here has been given value BY US
to steal.


ATTRIBUTION AND IDENTITY -- SAID PLAINLY
----------------------------------------

This project makes NO claim about who Satoshi Nakamoto was, and claims NO authorship of his code,
his whitepaper, or his name. Where it addresses identity it records what the evidence can and cannot
establish -- which, for authorship of a document, is that it cannot.

The chain started here has its own author, who holds its genesis key and can sign for it on demand.
That is a separate and provable claim about a separate and valueless chain. It is not a claim about
2009.
