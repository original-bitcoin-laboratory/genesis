How this is measured. A scheduled probe connects to each anchor over the real node wire (magic + checksum framing), does the version handshake, and walks getblocks to the tip — the same protocol any node speaks. No authority is involved; the durable guarantee is the reproducible genesis, not this page. A chain reads offline only if no anchor answered the probe. Not money.
