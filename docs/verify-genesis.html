Why this exists. The earliest Bitcoin survives as hash-identified source, and most claims about it circulate as lore. This is the smallest possible antidote: a block you can regenerate yourself, from the same bytes Satoshi used, with nothing to trust but SHA-256 and your own eyes. Everything runs inside this single file — save it (Ctrl/⌘-S) and it works forever, offline, and it can be shared device to device.

Not money. This verifies a historical block; it holds, moves, and is worth nothing. It is a reproducibility instrument, part of the Original Bitcoin Laboratory.
